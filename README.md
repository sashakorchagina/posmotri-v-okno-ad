# Посмотри в окно

Проектная работа Яндекс Практикума: поиск видео с видами из окон по городу и времени суток.

Репозиторий: https://github.com/Dashinoid/posmotri-v-okno-ad

## Как открыть

Откройте `index.html` в браузере. Для загрузки видео нужен интернет и доступ к API Практикума.

Макет рассчитан на ширину 1200 px. Используются HTML, CSS, Flexbox, локальные шрифты Fira Sans Condensed и Oswald. Логика поиска, переключения видео и подгрузки карточек взята из стартового репозитория.

## Возможности

- Поиск по городу и времени суток.
- Переключение видео нажатием на карточку.
- Подгрузка карточек кнопкой «Показать еще».
- Индикаторы загрузки и сообщения об ошибках.
- Клавиатурная навигация с видимым фокусом.

## Файлы

- `index.html` — исходная разметка и шаблоны.
- `styles/style.css` — оформление страницы и интерактивных состояний.
- `styles/preloader.css`, `styles/error.css` — исходные стили служебных состояний.
- `scripts/script.js` — исходная логика приложения.
- `fonts/` — локальные шрифты.
